## Примеры кода

### Задача с Codewars: "Even or Odd"

**Условие:** Напишите функцию, которая принимает целое число и возвращает строку "Even" (чётное) или "Odd" (нечётное).

**Решение на JavaScript:**

```javascript
function evenOrOdd(number) {
  // Используем оператор % для проверки остатка от деления на 2
  if (number % 2 === 0) {
    return "Even";
  } else {
    return "Odd";
  }
}

// Проверка работы функции
console.log(evenOrOdd(4));  // "Even"
console.log(evenOrOdd(7));  // "Odd"
console.log(evenOrOdd(0));  // "Even"
